# Titlul proiectului: Spiritul Crăciunului

Site-ul se încadrează în tematica de Crăciun și conține o prezentare a sărbătorii, acoperind mai multe arii: istoric, mod de celebrare pe întreg globul, filme și muzică de Crăciun. <br>
Vizitatorii site-ului își pot crea un cont pentru a îi putea trimite o scrisoare lui Moș Crăciun. Logica de backend a fost implementată folosind framework-ul FastAPI în Python.

Tehnologii utilizate: HTML, CSS, JavaScript, Python (FastAPI)
